# Design Guidelines Summary

Source: `/Users/evawu/Desktop/PureWave/BAT_PW/Green BlackWhite Design System/guidelines/`

The guidelines define a **dark, compact interface with bright tennis-inspired accents, strong typography, and rounded controls.**

| Area | Main rules |
|---|---|
| **Backgrounds** | Use near-black `#121212` with progressively lighter dark surfaces for cards and panels. Create depth mainly through shade changes. |
| **Accent colors** | Optic yellow `#e5f04d` highlights key numbers and primary actions; court blue `#176bbf` supports statement sections; court green `#1d7c53` marks featured content and positive states. Avoid using all three together or as a gradient. |
| **Text colors** | White for primary content; lighter-to-darker grays for supporting information. Use black text on yellow fills. |
| **Typography** | Build hierarchy primarily through **weight**, using regular 400 and bold 700, with semibold 600 sparingly. Titles: 24px; headings: 18px; body: 16px; captions: 14px; small text: 12px. |
| **Special text** | Reserve 10px text for legal copy and timestamps. Use JetBrains Mono only for durations, codes, and token values. |
| **Spacing** | Keep interface rows and components tight, using the 1–20px component scale. Use 24–64px spacing for marketing pages and larger sections. |
| **Shapes** | Buttons and navigation use pill shapes; icon controls use circles. Containers generally use subtle 2–8px corners, with larger radius options for panels. |
| **Depth and focus** | Default surfaces have no shadow; elevated elements use medium or heavy shadows. Focus uses a 1px white inset outline. |
| **Interaction** | Hover scales controls to 1.04; pressing scales them to 0.98. Ghost controls change color only, while cards lighten over 300ms. |

Two details matter when applying it:

- **The wordmark is provisional.** The example uses “Greenline” in Figtree 900 with a green dot because no logo was supplied.
- **The larger layout spacing is an extension.** The 24–64px scale was added for marketing pages and section rhythm rather than taken from the original source document.
